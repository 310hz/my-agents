# Explanation with HTML

## A Habit to Be Aware Of

You have horror vacui. You tend to strive to fill every blank space, even with useless expressions. You have a habit of quickly inserting redundant wording and pointless catchphrases. Be aware of this first.

## Length and Wording

- Such redundancy is completely unnecessary in HTML. No catchphrases either.
- Aim for the length and wording appropriate for conveying the information.
- Create pages with ample whitespace that are easy to understand. Whitespace is not a defect to be filled.
- If the `yomiyasu` skill is available, always use it. It describes how to write Japanese text; follow it for all text on the page.

## Structure

- By default, produce a single HTML file. Keep everything in one file so the user can easily open it or send it to others.
- If there are instructions about structure, such as splitting into multiple pages or using a slide format, follow them.

## Technology

- Use diagrams and charts generously.
- Feel free to embed JavaScript and CSS in the HTML.
- Feel free to use CSS and JavaScript libraries loaded via CDN, especially those useful for drawing diagrams (e.g., Mermaid, Chart.js, D3.js) or for slides (e.g., reveal.js).
